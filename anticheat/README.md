# OUTLANDS AntiCheat

Niezależny moduł ochrony gry. Docelowo będzie działał przede wszystkim po stronie serwera — klient nie może samodzielnie rozstrzygać o obrażeniach, punktach, prędkości ani wyniku meczu.

## Zakres
- Walidacja ruchu i prędkości po stronie serwera
- Walidacja strzałów, szybkostrzelności i obrażeń
- Wykrywanie anomalii wejścia i podejrzanych wzorców
- Ochrona stanu meczu i ekonomii
- Logowanie zdarzeń i system kar

AntiCheat nie będzie obiecywał wykrycia każdego makra lub autoclickera. Najważniejszą ochroną będzie autorytatywny serwer i walidacja działań.

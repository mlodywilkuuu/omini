# Company Empire

Prosta gra typu tycoon w przeglądarce.

## Jak grać?
- Twórz produkty 📦
- Zatrudniaj pracowników 👨‍💻
- Rób marketing 📢
- Przetrwaj losowe wydarzenia

## Uruchomienie
Otwórz `index.html` w przeglądarce

## Deploy (GitHub Pages)
1. Wgraj repo
2. Wejdź w Settings → Pages
3. Wybierz branch `main`
4. Gotowe 🚀

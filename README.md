# Omini — zimowa wioska

Projekt interaktywnej, eksplorowalnej wioski 3D. Rozwijany etapami.

## Struktura

- `wioska/` — główna scena 3D, teren, budynki i nawigacja.
- `gry/` — osobne minigry i ich wspólne elementy.
- `tracker/` — moduł śledzenia odliczania i wydarzeń.
- `assets/` — obrazy, modele 3D, tekstury, audio i fonty.
- `shared/` — współdzielone style i skrypty.

Każdy moduł będzie rozwijany niezależnie, a wspólne zasoby i komponenty będą przechowywane poza nimi.

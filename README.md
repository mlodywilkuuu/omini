# Retail Empire

Przeglądarkowy symulator grupy handlowej. Uruchom przez GitHub Pages lub otwórz `index.html` lokalnie.

## Funkcje
- Symulowane sieci: Tesco, Auchan, Carrefour, Kaufland, Lidl, Biedronka, Aldi, Netto, Żabka, Dino i Intermarché.
- Kupowanie udziałów i przejmowanie kontroli po zgromadzeniu pakietu co najmniej 50%.
- Zakup pojedynczych sklepów konkurencji.
- Modelowane przychody, zyski, wyceny, udziały rynkowe, wzrost i marże.
- Statystyki segmentów: hipermarkety i supermarkety, dyskonty, convenience, e-commerce oraz handel Europy Środkowej.
- Symulacja upływu dni, miesięczne zmiany rynku, historia finansowa i zapis w localStorage.

## Ważne
Dane spółek i rynków są fikcyjnymi parametrami gry, a nie rzeczywistymi danymi finansowymi lub rekomendacją inwestycyjną. Zapis gry przechowywany jest lokalnie w przeglądarce.

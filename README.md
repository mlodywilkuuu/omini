# Symulator Parlamentu — Polska

Przeglądarkowy sandbox polityczny osadzony we współczesnej Polsce. Gracz jest liderem własnej partii politycznej.

## Uruchomienie
```bash
npm install
npm run dev
```

## Funkcje prototypu
- Dashboard państwa, wskaźniki gospodarcze i dziennik wydarzeń.
- Tworzenie i edycja własnej partii.
- Kampanie zwiększające poparcie.
- Sejm z 460 mandatami i podglądem układu sił.
- Projekty ustaw, lobbing i głosowania.
- Sondaże i symulowane wybory z progiem 5%.
- Decyzje gospodarcze i negocjacje koalicyjne.
- Upływ czasu i codzienna aktualizacja wskaźników.

Wartości startowe i ugrupowania są fikcyjnymi danymi rozgrywki inspirowanymi polskim systemem parlamentarnym, nie bieżącym sondażem ani oficjalnym składem Sejmu.

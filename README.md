# Santa Tracker — Live Flight

Świąteczny tracker lotu Świętego Mikołaja z interaktywną mapą, statystykami i sterowaniem symulacją.

## Uruchomienie

Projekt jest statyczną stroną. Otwórz `index.html` lokalnie albo włącz GitHub Pages:

1. Wejdź w **Settings → Pages**.
2. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
3. Wybierz branch **main** i folder **/(root)**, a następnie zapisz.

## Funkcje

- ciemna mapa świata oparta o Leaflet i CARTO
- animowana pozycja sań na trasie
- statystyki lotu i postęp misji
- pauza, wznowienie i reset symulacji
- dziennik zdarzeń
- układ dopasowany do telefonu i desktopu

> To demonstracyjna symulacja — pozycja i statystyki nie pochodzą z rzeczywistego nadajnika GPS.

Mapa wymaga połączenia z internetem, aby pobrać biblioteki i kafelki mapy.
